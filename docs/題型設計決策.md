# 題型設計決策

> 狀態：**現行**（2026-09-30 自後端 `docs/guide/` 與 `CLAUDE.md` 整理而來）。
> 記錄「各題型**為什麼**這樣出題、這樣排」的教學設計決策，讓日後新增或改編題型時能沿用同一套想法。
> 通用的版面與量詞規範見 [`教材設計規範.md`](教材設計規範.md)；計算格見 [`輔助計算格規範.md`](輔助計算格規範.md)。

## 1. 題型命名

**格式**：`[主題名稱]＿[步驟數][運算]（[位數]）`，例如「購物找零＿兩步驟乘減（兩位數）」。

**原則（仿康軒風格，與課堂術語一致）**：
- 動詞優先：「計算」「找出」「畫出」「分分看」「最多能買」。
- 位數明示：「兩位數」「四位數」。
- 進退位明示（初學階段）：「不進位」「不退位」「進位」「退位」。
- 步驟數明示（多步驟）：「一步驟」「兩步驟」「三步驟」。

**新題型命名時**：先查康軒課本對應單元名稱，提供 2–3 個候選命名給老師選擇。

**已查閱的對應關係**：

| 本系統題型 | 康軒對應單元 | 康軒活動名稱 |
|---|---|---|
| 不進位的加法（四位數）＿畫錢幣輔助 | 三上第二單元「四位數的加減計算」 | 活動一：不進位的加法 |
| 不退位的減法（四位數）＿畫錢幣輔助 | 三上第二單元「四位數的加減計算」 | 活動三：不退位的減法 |
| 購物找零＿兩步驟加減（四位數） | 三上第二單元「四位數的加減計算」 | 含進退位的加減混合 |
| 購物找零＿兩步驟乘減（兩位數） | 二下「乘法」＋「加減應用」 | 先乘後減兩步驟 |
| 分分看＿一步驟除法（兩位數） | 二下「除法」 | 等分除概念 |
| 平分問題＿一步驟除乘（兩位數） | 二下「乘除關係」 | 平分→乘法連結 |

## 2. 通用出題慣例

**每份先示範、再隨機**：每份學習單第 1 題為固定的示範題（附答案），讓學生先看再做；其餘題目隨機出題。（例：認識錢幣系列，6 題位值板，第 1 題示範、第 2–6 題隨機。）

**填空題（數列、「寫一寫」）的留白規則**：
- **第 1 格一定填好**——讓學生看得出數列從哪裡開始。
- **空格彼此不相鄰**——每個空格左右都有已填的數字可以推。
- 用意是讓學生**從前後的數字推出空格該填多少**；全部印出數字就沒有可作答的地方。
- 留白時字級一併縮小一點，避免數字貼著框線、和隔壁格視覺上連在一起。
- 例：「寫一寫」8 格隨機留 3 格；「數到 200」數列公差 10，首項 100～250（整十），六項最大 300（維持三位數）。（實作：`generators-sub-borrow.md`「寫一寫改成部分留白」、`generators-count.md`「N101G」。）

**題目排列**（綜合練習）：
- 作答方式相同的題目**集中排在一起**（例如畫錢幣、畫記的題型整組放最後），避免大面積空白方框把純計算題切散。
- 其餘題型輪替，**避免同一種運算連續出現**，學生仍須自行判斷該用加還是減。
- 版面是雙欄，**題數湊成偶數**，最後一列右欄才不會空一大格。

**輔助列留空是刻意的**（例：N209B 乘法基本計算）：計算格的進退位列在產出的檔案裡是空的，不是因為該題不會進位，而是留給學生自己寫。

## 3. 認識錢幣系列（難度層次）

**難度層次**（每道題允許出現的幣值）：

| 層次 | 允許幣值 | 特殊幣 |
|---|---|---|
| L1 | 100、10、1 | 無 |
| L2 | 100、10、5、1 | 5 |
| L3 | 100、50、10、5、1 | 50 |
| L4 | 500、100、10、1 | 500 |
| L5 | 500、100、50、10、5、1 | 5、50、500 三種隨機取一（也可能不出現） |

- **特殊幣（5、50、500）每道題最多 1 種、只出現 1 枚**。
- 位值板欄位容量：百欄最多 3 枚、十欄最多 4 枚、個欄最多 4 枚。
- 兩種風格：simple（圖示）、photo（實拍）。
- **進位版**：`coincarry10` 固定個位欄 1 元進十位，無難度選項；`coincarry` 為 L2–L4，十位欄進百位（L1 已移除）。

## 4. 加減混合＿手勢版

設計意圖：讓學生**看錢幣圖算出**「原來有／拿走／放進／剩下／共有」。

- 每張卡片畫三組錢幣：撲滿裡（黑，原來有）、拿走的手旁（橘）、放進的手旁（綠），以**顏色加位置**區分。
- 樣式：雙圈＋數字，10 元一列在上、1 元在下。
- **教學設計（2026-09-30 老師定案）：十位與個位都至少 1 個，且不進位、不退位**，讓學生專注在「原來有／拿走／放進」的意義，不同時處理進退位。
- 這組限制同時也讓錢幣畫得下：「拿走」欄最窄（約 40pt），第二步最多 3 個十元；程式畫不下會直接報錯，不會溢出。（實作是版面先決定了這組範圍，現在正式確認為教學設計，日後調整範圍時要一併考慮教學目標。）
- 答案空格留白給學生填。
- （實作：`generators-other.md`「空白練習改成數錢幣作答」。）

## 5. 提示漸退：從提示算式到「自由列式」

設計意圖：同一個情境（同一張價目表、同一道題）依學生程度**逐步撤掉算式提示**，最後只留答案位置，讓學生自己決定怎麼列式。依據 N209E 算價錢老師手調的「買兩樣（自由列式）」範本（2026-10-01）整理。

**三個提示層級**（同一題型可並列成多個版型，老師依程度挑）：

| 層級 | 名稱（版型後綴） | 步驟格裡有什麼 | 算式列 | 例 |
|---|---|---|---|---|
| A | 完整提示（不加後綴） | 方框數＝項數（□+□+□）、運算符號、□×○、已知數先填好 | `___ + ___ = (  )`、`⇨ 367 – (  ) = (  )` | N209E 買兩樣 |
| B | 去掉某一步提示（「去掉連加」等） | 只留目標表示法（□×○＝（ ）） | 同 A | N209E 買兩樣（去掉連加） |
| C1 | 自由列式：淡化提示 | 與 A 相同的提示內容，但**全部刷淡**到列印後隱約可見（紅 □＋→淡粉紅、灰字→淡灰、○ 外框與計算格格線一併調淡） | 同 A，淡灰 | N209E 買兩樣（自由列式：淡化提示） |
| C2 | 自由列式：無提示 | **全空白**（只留指示用的箭頭），**連輔助計算格也不顯示**（實作為「提示透明」，版面與 C1 完全相同） | `______________ = (    )` | N209E 買兩樣（自由列式：無提示） |

**單步驟題的對應（N209B 價目表・文具，2026-10-01）**：N209B 每張卡只有一步（買 N 個要多少錢），A 層級的提示是 `□ × ( ) = ( )`（□＝單價）加「⇨放進格子算算看」與直式計算格，沒有連加、沒有步驟格。兩種自由列式照同一條界線做：C1 淡化提示＝`□ × ( ) = ( )` 與「⇨放進格子算算看」刷淡、計算格格線與進位列底色刷淡（粗黑結果橫線不動）、鉛筆圖保留；C2 無提示＝算式列改成 `______________ = (    )`，「⇨…」、計算格（含進位列底色、對齊箭頭「↓」）、鉛筆圖全部拿掉，只留題目與「答：一共（ ）元」。版型名「價目表（文具：完整提示／自由列式・無提示／自由列式・淡化提示）」。

**自由列式「拿掉」與「保留」的界線**——拿掉的是「怎麼算」，保留的是「算什麼、答在哪」：

- **拿掉（會洩漏解法的提示）**：方框／圓圈的個數（暗示項數或乘數）、運算符號（＋ − × ⇨）、先填好的已知數、提示文字的灰色樣式。
- **保留（情境與作答結構）**：價目表與題目圖、題號與步驟切分（分格、箭頭指出「這格算這樣商品」）、答案位置與單位（「＝（ ）」「一共（ ）元」「找＿元」）、付款金額等題目資料。
- **直式計算格依層級處理**：C1 淡化提示＝格線與輔助列刷淡（見 [`輔助計算格規範.md`](輔助計算格規範.md) 層級 2b），學生隱約看得到、不再依賴；C2 無提示＝整組不顯示（含答案橫線；實作為透明，位置不變）。淡化時**答案橫線維持粗黑**（它是作答的結構線）。
- **刷淡的程度**：目標是「列印後隱約看得見就好」——灰階不低於約 #DDDDDD、有彩度的顏色（紅）淡到粉紅即可，不壓成髒色。
- **題目難度、數字範圍、版面高度都不變**：自由列式只撤提示，不換題、不縮格（學生要自己寫算式，空間反而更需要）；頁數必須與 A 層級相同。

**版面規則**：
- 清空後的同一步驟格子**寬度均分**——原本依提示內容（例如 3 項 vs 5 項連加）配的寬度已無意義，左右對等才符合「同型元素等大小」。
- 算式列改成**一條長底線＋「＝（ ）」，一行放得下**；放不下時加寬該欄（從相鄰欄扣，表格總寬不變）。
- 命名：版型名加「（自由列式）」，下載檔名加「自由列式」，例如「算價錢_買兩樣自由列式」。

**（C1、C2 兩種都做，老師依學生程度挑。）

適合做自由列式的題型**：有「提示算式」的應用題（`⇨ ___ – ___ = (  )`、`□+□+□`、`□×○` 這類）。純計算題（直式本身就是題目）、數數與畫記類不適用。（實作：後端 `docs/guide/free-form-variant.md`，含自動轉換工具與候選範本清單。）
