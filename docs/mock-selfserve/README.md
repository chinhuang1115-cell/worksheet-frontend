# 自助選購型店家模擬圖（2026-11-17）

文具店、糖果餅乾店、玩具店改成「在展示架上挑 → 放進購物籃 → 到櫃台結帳」。以下 4 個方向，以文具店為例（第 4 關：買 2 枝鉛筆＋1 本筆記本）。重產：`CHROME_PATH=<chromium> python3 docs/mock-selfserve/make.py`。

| 圖 | 方向 | 優點 | 缺點（特教學生／平板／工程量） |
|---|---|---|---|
| `A_同一畫面.png` | 貨架＋櫃台同一畫面，顧客提籃子走動 | 一眼看懂「店」的全貌；最貼近現有版面；工程量最小 | 一個畫面東西多（貨架、櫃台、人、籃子、任務卡），專注力較分散；貨架小、標價牌小，平板點選容易誤觸；人物走動動畫要算路線 |
| `B_兩個場景.png` | 場景 1 貨架區大畫面 → 過場 → 場景 2 櫃台 | 一個畫面一個重點（先挑、再結帳）；貨架可放大、標價清楚；櫃台完全沿用現有程式（托盤換籃子）；「換地方了」有明確過場 | 多一個場景與過場動畫；貨架要新做；看不到櫃台，學生可能不知道還有結帳 |
| `C_店內地圖.png` | 俯視平面圖，點某一排放大挑 | 有空間感、有探索趣味；每次放大只看一排，東西少 | 步驟最多（地圖→放大→回地圖→櫃台），認知負擔重；俯視圖抽象，識字／空間概念弱的學生不一定懂；工程量最大 |
| `D_走道捲動.png` | 走道左右捲動，底部籃子固定，最後是櫃台 | 一次只看 3 樣、東西最大；籃子與任務卡固定在下方，專注；像真的走過走道 | 要左右捲動／按箭頭，部分學生易迷路、漏看某一段；「去結帳」要走到最後，操作較長；貨架需分段 |
| `糖果店貨架.png` | 糖果用「罐子」（1 個 N 元）、餅乾零食用架子 | 不同店擺設不同（糖果罐、零食架）；點一下罐子＝拿 1 個，貼近生活 | 罐子裡的圖是示意，每種糖一罐，最多約 5 罐＋4 架，超過要分頁 |

## 推薦：B（兩個場景）
- 符合「一個畫面只放一個重點」：挑選與結帳分開，任務卡與籃子在貨架區底部一直看得到。
- 結帳場景沿用現有櫃台、算錢、付錢、找錢流程，改動集中在「前面多一段挑東西」，風險最小。
- 貨架可以放大，標價牌清楚，平板操作不易誤觸；三家店只需換貨架內容（文具架、糖果罐、玩具架）。
- 備案：若想要更有「走在店裡」的感覺，D 可作為 B 的貨架區升級（貨架分段捲動）。
