# 給後端 session 的提示（複製貼上用）

```
請實作「認識錢幣」的外觀改版與自由排列。規格與數據都已在前端 repo（chinhuang1115-cell/worksheet-frontend）定案，請先讀：
- docs/後端實作順序清單.md（先做什麼、做到什麼算過）
- docs/後端交接_錢幣自由排列與外觀.md（規則細節，§2 外觀、§3 排列、§4.1 混合位值）
- docs/mock-coin-free/*.png 與 *.html（視覺依據；coin_geom.js、coin_mix_free.html、coin_special_free.html 可直接讀演算法與座標）

【順序】
1. 外觀改版（單獨驗收）：重畫 backend/coinvalue_media/simple/ 的 coin_*.emf（含 1000 元）——100/500/1000 長方形加底色與深色粗體數字、外框改單層 #222、5/10/50 與三種長方形幣加淡灰內圈（1 元不加）。photo 不動。重做 sample PDF。
2. 共用放置模組：圓形幣用圓心距離碰撞、長方形幣用旋轉後外接框、最小間距 5px；大的先放、放不下整輪重來、連續失敗要報錯（不可靜默失敗）。
3. 試水 coincarry1000 L2：半自由（區＝欄界各內縮 8px、特殊幣 500 固定在百位區左上不放大、傾斜 ±4°）→ 完全自由（位值傾向：本題面額由高到低排目標位置，x 取常態分布 sd=0.16×框寬、10% 純隨機；500 隨機；傾斜 ±10°）。
4. 擴到 coincarry（半自由內縮 6px）、coincarry10（內縮 8px；十位區最窄，10 元不可超過 6 枚）。完全自由的 5 元畫大為 1 元的 1.3 倍。
5. coincarrymix：完全自由直接做；半自由「不加寬框」，內縮 2px（欄界：完全自由固定 62/196/277；半自由 2026-10-09 起改為每題依各欄錢幣量重分，見交接文件「欄位寬度規則」），整理欄欄界同步改用。
6. 交疊（預設開啟、可開關 overlap=0.3）：每對面積各自 ≤30%、<4% 不要、不可蓋到對方中央數字保護區、每枚最多 1 個交疊對象、約 60% 的幣可交疊；半自由的特殊幣不交疊。

【已定案】每次下載重新隨機（種子留成可選參數）；交疊預設開啟；不進位版（coinvalue 系列）不做自由排列，只套用外觀；題目、答案、枚數、頁數、整理欄寫法（第 1 題示範題含劃掉與橘字進位）與位值板版完全相同；版型名加「（半自由排列）」「（完全自由排列）」，registry 新增「排列」維度，不要沿用 L 編號。

【要特別驗證】
- 錢幣現在是浮動 EMF（wp:anchor、relativeFrom=character/line）。Word 與 LibreOffice 因 docGrid 原點會差幾 pt：一題所有錢幣請錨在同一段落、同一原點，兩邊都量。
- 傾斜用 a:xfrm rot；先試一枚確認 LibreOffice 轉 PDF 時旋轉 EMF 不糊、不偏位（有問題的備案：旋轉的幣改用 PNG，或用 /bake 烘成圖）。
- 交疊上下層用遞增 relativeHeight；旋轉繞中心，posOffset 要由中心座標換算。
- 灰階檢查；實際列印確認淡灰 #BDBDBD 夠不夠明顯（太淡改 #A8A8A8 並回報前端）。
- 驗收：最密題連跑數十份不報錯、不重疊、不出框；頁數不跳；超過 30% 與遮到數字都是 0 對。

【做完】更新後端 docs/guide/generators-coin.md、toolkit/RULES.md 題型清單；經驗與踩坑寫進 docs/guide/。前端收到新 registry（python toolkit/sync_registry.py）後會換 assets/*.pdf、assets/img/、bump SAMPLE_VER，並接手題型面板的「排列」選項。
```
