## 三種難度對應紙本

| 互動版 | 紙本提示版型 |
|---|---|
| 強提示（level 3） | 完整提示 |
| 弱提示（level 2） | 淡化提示 |
| 無提示（level 1） | 自由列式（無提示） |
| （未實作）逐題漸退 | 逐題漸退淡化提示（見下方「未規格化」） |

URL 的 `mode=full|faded|free` 只決定**第一次**開啟的預設難度；之後以瀏覽器記住的 `wp_level` 為準，右上角可隨時切換（切換＝這題重來）。

## 提示設定檔（2026-10-14 起，強／弱／無的權威來源）

[`dashboard/hint-profile.json`](../dashboard/hint-profile.json) 把「強／弱／無各開哪些功能」寫成機器可讀的設定：`flash`、`helpAfter`、`tipbox`、`autoRead`、`liveColor`、`autoDo`、`wrongDetailAfter`、`colIcon`、`keypadDim`、`focusDim`、`spot`、`carryFlash`、`numColor` 共 13 項。

- 後端 `python toolkit/sync_hint_profile.py` 同步成 `backend/hint_profile.json`，產生互動頁時內嵌進 `SPEC.hintProfile`，模板用 `H('功能')` 讀值。**要改行為＝改設定檔，不要在模板寫死 `level===N`。**
- 自動化驗證：`python toolkit/test_hint_profile.py [pv|cy]`（Playwright，三種難度各跑一輪，對照設定檔檢查提示框、欄標題圖示、拖曳即時變綠紅、錯誤回饋文字、連錯閃動門檻、自動朗讀、強提示代做）。smoke 另有 `interactive hint profile` 檢查設定檔完整、模板用到的鍵都有定義。
- `adopted`＝已有自動測試的題型（目前：錢幣位值、錢幣進位、加減、乘法概念、乘法應用題、直式乘法、圓盤）。

### 2026-10-14 定案的 4 個決定
| 項目 | 決定 | 強 / 弱 / 無 |
|---|---|---|
| 連錯後閃出正確位置 | 三級都閃，門檻不同 | 2 次 / 3 次 / 4 次 |
| 提示框（文字提示） | 強、弱有（弱不閃、不自動念），無沒有 | 有 / 有 / 無 |
| 放錯的回饋 | 無提示先說「再試一次」，同一步驟累計錯 3 次才具體說明 | 立即 / 立即 / 第 3 次起 |
| 強提示代做 | 只代做重複性機械步驟（學生完成判斷後的搬移、換錢動畫）；圈包、選算式、計算、填寫由學生做 | 代做 / 否 / 否 |

這些決定也套用到加減、乘法（概念、應用題、直式）與圓盤：弱提示會顯示提示文字；連錯閃動、放錯回饋照設定檔。已用 `test_hint_profile.py flow` 逐題型、逐難度驗證（開場閃動、連錯 1～4 次的回饋與閃動、滑鼠實拖做完第一題）。

## 逐題漸退規格（2026-10-14 定案並實作）

不參考紙本版，只依互動版本身的邏輯。使用者選「分組退場」，且**文字語音先退、視覺後退**。

**三組提示**（鍵對應見 `hint-profile.json` 的 `groups`）：視覺 `see`（閃燈、進退位閃、鍵盤亮暗、整欄聚焦、聚光燈、拖曳變綠紅、數字上色、欄標題圖示）、文字語音 `say`（提示框、自動朗讀、具體錯誤說明、連錯閃動門檻）、代做 `do`（強提示代做機械步驟）。每組各自有難度（3 強／2 弱／1 無），再去 `features` 查該難度的值。

**五個階段**（每格是該組此時的難度）：

| 階段 | 視覺 see | 文字語音 say | 代做 do | 學生感受 |
|---|---|---|---|---|
| S1 | 強 | 強 | 強 | 完整協助 |
| S2 | 強 | 弱 | 弱 | 提示框還在但不閃不念；不再代做 |
| S3 | 強 | 無 | 無 | 沒有文字語音，只剩視覺輔助 |
| S4 | 弱 | 無 | 無 | 視覺輔助也減半（只剩聚光、不閃） |
| S5 | 無 | 無 | 無 | 完全無提示 |

**規則**
- 第 *i* 題（從 0 起，共 *n* 題）用階段 `floor(i × 4 ÷ (n−1) + 0.5) + 1`（.5 進位）：第 1 題固定 S1、最後一題固定 S5，中間平均分配（n=3 → S1,S3,S5；n=5 → S1…S5；n=10 → S1,S1,S2,S2,S3,S3,S4,S4,S5,S5）。
- 只往下退、不回升；同一題內不變，換題才換。
- 最後一題一律 S5，錯誤回饋照無提示規則（先說「再試一次」，累計錯 3 次才具體說明）。
- 選用的「連錯停留」（某題累計錯 ≥3 次，下一題不前進一階）**預設關閉**，設定檔有開關 `graded.rules.hold`。
- 入口：網址 `?lv=graded`，由老師用連結開啟；漸退模式下隱藏右上角強／弱／無切換；中途換模式＝整份重來；不對學生顯示階段名稱。
- 紀錄：成績 `level='graded'`，加 `graded:[{q, stage, perfect}]`。
- 未列入三組的結構性功能（步驟跳過、圈圈編號等）不受影響。

**實作現況**：模板已實作（`H(k)` 依該題階段取值）；總覽頁有「漸退」按鈕；`test_hint_profile.py graded` 對錢幣位值驗證 n=3／5／10 的階段對應與 n=5 逐題行為（68 項）。其他題型只做過載入、未逐項驗證；選用的連錯停留未實作。

## 點一下朗讀（2026-10-14）
取代滑過朗讀（平板沒有滑鼠）：點一下文句、語詞、圖片、選項、已填的格子、步驟標題就念；滑鼠移過去不念；拖曳過去再放開不算點一下；空格、功能按鈕、錢幣圖示不念。點選項磚、數字鍵時照舊動作（放進格子、輸入數字），同時念出那一個字。若要改成「第一下念、第二下才放」，需先決定備援點選的規則。三種難度行為相同。測試：`test_hint_profile.py tapread`。

## 連錯停留（選用，已實作、預設關閉）
漸退模式下，某題累計放錯達 `graded.rules.hold.wrongAtLeast`（3）次，後面各題少前進一階；最後一題仍是最後階段。設定檔 `graded.rules.hold.enabled` 改 true 才會生效。測試：`test_hint_profile.py hold`。

## 步驟朗讀與完成讚美語（2026-10-14）
- **步驟朗讀**：步驟一開啟，先念步驟標題，再念這一步要作答的問題，**念完才開放作答**（朗讀期間罩住作答區，頂端列不受影響）。設定檔鍵 `readTitle`、`readAsk`，強提示開、弱／無關，屬文字語音組（漸退時跟著先退）。問題文字不洩答案。
- **完成讚美語**：原本固定的「完成了！」改為常見讚美語（一次答對、有錯各一組），隨機、不重複（洗牌發牌，發完才重洗，相鄰不相同）。
- 自動測試：`test_hint_profile.py voice`（錢幣位值、加減、乘法）。

## 系統用字：簡單、易懂、生活化，盡量不用數學術語（2026-10-14）
給學生看、聽的所有文字（步驟標題、要作答的問題、提示、錯誤回饋、讚美語、按鈕）：一句話只講一件事，用日常說法；課本一定會教、畫面上也寫了的詞（例如欄標題「百位」）才保留。

| 避免 | 改成 |
|---|---|
| 運算符號 | 記號 |
| 個位（指方向時） | 最右邊 |
| 連加 | 一個一個加起來 |
| 直式 | 把數字排整齊 |
| 幾倍 | 有幾份一樣多的 |
| 關鍵字 | 題目最後在問什麼 |

**新寫的文字照此寫；既有文字（步驟標題、各處提示與錯誤回饋）尚未全面盤點**——下一步：列出清單，讓使用者確認改法後一次改完（改字會影響語音念法與自動測試的預期文字）。寫法與念法不同時用後端的 `SAY_MAP`（寫法→念法），不要為了語音改畫面文字。

## 新建互動頁怎麼套用
1. 對照 `spec.json` 的 `adopt` 欄（must＝新頁面必備、should＝建議、opt＝視題型）列出要套用的功能，連同設定檔鍵一起交給後端 session。
2. 要用到的提示功能直接讀設定檔（模板用 `H('鍵')`）；需要新功能時，在 `hint-profile.json` 加一個鍵＋三級的值，同步後端，並在 `test_hint_profile.py` 補對應檢查；`spec.json` 同步更新。
3. 做完後在 `dashboard/catalog.json` 新增頁面變體；用 `python dashboard/check_catalog.py <後端路徑>` 確認沒有漏列端點，再 `python dashboard/make_thumbs.py <後端路徑> <新 id>` 產生統整頁縮圖。

## 維護規則（即時更新）
- **新增或修改互動頁 → 同一個 commit 更新 `dashboard/catalog.json` 與（若行為改變）`dashboard/spec.json`，並更新兩檔的 `updated`**（總覽頁 `/interactive/` 讀 catalog.json，合併到 `main` 後 GitHub Pages 約 1 分鐘生效）。

## 步驟③計算提示框與自動朗讀（2026-10-15）
- **計算提示框**（設定檔鍵 `calcTip`）：直式計算的分步提示放在直式右側的**懸浮提示框**（分步計算框的上方），每個階段做完淡出再換下一句；**強、弱提示有，無提示沒有**。第一句是蛋糕比喻：「把數字像蛋糕一樣，一層一層地放整齊。記得：百元對百元、十元對十元、1元對1元。」
- **自動朗讀**（設定檔鍵 `readCalcTip`）：**弱提示自動念**（含第一句，因為弱提示不念步驟標題）；**強提示不自動念、點一下才念**（互動頁是練習與教學的媒介，細節只當備用）；無提示沒有提示框。句子超過兩句時分句停頓（語速快 0.7 秒）。
- 目前只有加減（wordprob）已實作，自動測試：`test_hint_profile.py calc`；乘法直式（mulv）尚未套用。
