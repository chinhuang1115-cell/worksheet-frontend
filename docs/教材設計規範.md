# 教材設計規範

> 狀態：**現行**（2026-09-30 自後端 `toolkit/RULES.md` 整理而來）。
> 本文件回答「教材**應該長什麼樣子、為什麼**」；怎麼用程式畫出來、Word／LibreOffice 兩邊如何驗收，見後端 repo（`worksheet-backend`）的 `CLAUDE.md`、`docs/guide/` 與 `toolkit/RULES.md`。
> 直式加減乘的計算格另有專文：[`輔助計算格規範.md`](輔助計算格規範.md)。

## 1. 使用對象與設計原則

使用者是特教老師，教材給**認知能力較弱**的學生使用。改編現有教材時，一律朝下列方向：

- **視覺化**：能用圖、格、顏色表達的，不只靠文字。
- **結構化**：步驟拆開、位置固定，同類題型每次長得一樣，換題不必重新適應。
- **生活化**：情境取自購物、找零、扭蛋等學生熟悉的事物。
- **簡單易懂**：一個畫面只放一個重點；用詞、量詞與圖片語意一致。
- **可漸進撤除**：同一題型提供由多到少的輔助（示範引導 → 計算格 → 無輔助），老師依學生程度挑選。
- **黑白列印仍可辨識**：不只靠顏色區分，形狀、位置、線型也要有差異。

## 2. 版面共同規格

**版面均衡對稱是硬性要求。** 以下規格適用所有學習單（不論新舊、固定版型或動態）。

| 規格 | 要求 |
|---|---|
| 左右對稱 | 雙欄（雙頁）左右的橫框線上緣、寬度、欄距相同 |
| 同型元素 | 同類題目卡／框大小、高度、間距一致；框間、物品列上下不貼死（至少 8pt） |
| 對位與置中 | 數字、標記、答案線、頁碼落在該在的位置，不靠空白字元湊 |
| 完整呈現 | 圖形不被裁切、輪廓不缺角、格子不被切半 |
| 頁數穩定 | 沒有空白頁；題目卡不跨欄斷開；最後一頁內容底緣離版心底線至少約 10pt |
| 視覺重量協調 | 題目數字字級不超過 15pt；淡色與粗黑線各司其職；示範與練習有明確區分 |

**上下邊距平衡**：頁面上邊距（頁首到表格上緣）與下邊距（表格下緣到頁尾）目視差距不超過一行文字高度（約 0.5 cm）。

**圖片不貼表格邊**（凡程式動態放入圖片的儲存格；固定版型的圖片由範本控制，不適用）：

| 方向 | 最小間距 |
|---|---|
| 左側 | 8 mm 以上 |
| 下側 | 5 mm 以上 |

**多題並列時，同欄列高相等**：上下排列的多題若列高不同、視覺不整齊，改為固定等高；同一欄的所有列高度相同，左右欄高比例依格數維持整頁填滿。

> 量測方式與容許值（例如左右差 ≤ 0.3pt、用 `smoke_test.py --layout` 檢核）屬實作，見後端 `CLAUDE.md`「版面驗收鐵則」。

## 3. 量詞

**量詞必須與圖片語意一致。** 新增商品到圖庫時，必須同時設定對應量詞。

| 類型 | 量詞 | 範例 |
|---|---|---|
| 杯裝飲料 | 杯 | 珍奶、奶茶 |
| 單枝鉛筆 | 枝 | 鉛筆 |
| 盒裝文具 | 盒 | 色鉛筆組、蠟筆盒 |
| 成套玩具 | 套 | 積木組、疊疊環 |
| 單隻動物玩具 | 隻 | 玩具熊 |
| 單輛車 | 輛 | 玩具車 |
| 成組玩具 | 組 | 保齡球組、玩具火車 |
| 便當 | 個 | 各式便當 |
| 咖哩飯 | 份 | 咖哩飯 |
| 冰淇淋 | 球 | 冰淇淋 |
| 棒棒糖 | 支 | 棒棒糖 |
| 棉花糖 | 包 | 棉花糖 |
| 一般物品 | 個 | 訂書機、削鉛筆機等 |
| 橡皮擦 | 塊 | 橡皮擦 |
| 尺 | 把 | 尺 |
| 剪刀 | 把 | 剪刀 |
| 膠水棒 | 條 | 膠水棒 |

**套用範圍（全部同步）**：題目文字（「買 1**杯**」）、計算格標籤（「買 2**杯**」…）、答案欄（「最多可以買（　）**杯**」）。

## 4. 答案的合理範圍

題目的數字必須符合生活常識與教學目標，不合理的組合不出題。

| 題型 | 規則 |
|---|---|
| 找零題 | 付款金額大於購買總額；找零不為負數或零；付款金額取整百（向上進位） |
| 最多可以買幾個 | 答案落在 **3～5 個**；答案 ≤ 1 或 ≥ 6 不出題 |
| 固定版型除法題 | 商落在 2～9 且整除 |
| 兩位數乘一位數（價目表、扭蛋） | 價格與次數的乘積不超過 99 |

驗算失敗時，寧可不產出，也不產出錯誤的學習單。（實作見後端 `toolkit/RULES.md` 第 3 節。）

## 5. 文字與格式

- 字型：**標楷體**。
- 量詞替換範圍：題目文字、計算格標籤、答案欄，全部同步。
- 多頁共用的價目表，各頁價格必須一致。

## 6. 主題與題型的位數對應

**主題的商品單價必須與題型的位數相符**，避免出現「千元的家電配兩位數加法」這類不合理情境。

主題依商品單價分成三個層級（後端 `library.json` 每個主題的 `tier` 欄位是**唯一權威來源**）：

| 層級 | 單價範圍 | 主題 |
|---|---|---|
| d2（兩位數） | 10–99 元 | 飲料店、文具店、甜點店 |
| d3（三位數） | 100–999 元 | 文具店＿進階、玩具店、便當店、玩具車、懷舊玩具、童裝店 |
| d4（四位數） | 1000–9999 元 | 鞋子店、體育用品店、3C產品店 |

- 家電行暫不開放（冰箱、洗衣機等會超過四位數）。
- **定價要貼近市價**：商品若在真實市場不屬於該層級，就換品項，不硬調價格。（例：手機、筆電的入門款常上萬元，不適合放進 d4，已改用電競滑鼠、機械式鍵盤等 3C 周邊；童裝的真實行情多在 150–1000 元，所以從 d4 改列 d3。）
- 新增主題時，先判斷商品單價區間再歸類；**同一個商品的價格，在所有題型都要落在同一區間內**，不可同一杯飲料在某題型顯示 35 元、另一題型卻隨機成 45–70 元。
- **跨層級的題型必須明示**：少數題型的版型之間位數不同（例如兩位數不退位應用題：「被減數兩位版」用 d2、「標準版」用 d3、「混合版」兩種都用）。混合版一定同時用到兩個主題的商品，畫面上要明白標示；**跨主題本身不是問題，靜默跨主題才是問題**。
- 程式端如何限制（`themes_for_tier()`、前端主題選單過濾），見後端 `toolkit/RULES.md` 第 7 節。

## 7. 時鐘

- 外圈：60 格分鐘刻度（整 5 分較長、每分鐘較短），**無數字**。
- 內圈：1–12 數字刻度。
- 時針：明顯比分針短（約分針的 75%），深色、較粗。
- 分針：接近外圓邊緣，金色（`#B8860B`）。
- 兩支針都比一般時鐘長，讓學生更容易判斷指向位置。
- 角度：時針 ＝ 小時 × 30° ＋ 分鐘 × 0.5°；分針 ＝ 分鐘 × 6°。
