# 拿錢互動頁（拿出指定的錢／湊到指定的錢）規劃

> 狀態：**已實作（2026-11-11；後端 `/interactive/take-money`，見第 6 節；尚待使用者在平板試手感）**。在後端 repo 實作（`templates/interactive/coin.*`、`interactive_wordprob.py`、`main.py`），再回本 repo 更新 `dashboard/catalog.json`／`spec.json` 與縮圖。
> 模擬圖：[`docs/mock-take-money/`](mock-take-money/)（`python docs/mock-take-money/make.py <後端路徑>` 重產）。

## 1. 需求（使用者 2026-11-11）

現有錢幣互動頁都是「看錢 → 數出多少元」（錢幣位值、錢幣進位）。這次做反方向：**給金額 → 學生自己把錢拿出來**。共三頁：

| 頁 | 名稱（暫定） | 內容 |
|---|---|---|
| 1 | 拿出指定的錢 | 只用普通幣值：1、10、100、1000 元 |
| 2 | 拿出指定的錢（有 5 元、50 元、500 元） | 加入特殊幣值 5、50、500 |
| 3 | 湊到指定的錢 | 畫面上已經有一些錢，從現有的金額往上加，湊到指定的數 |

## 2. 金額分段（參考康軒「數與量」各冊的數量範圍）

⚠️ 單元名稱是依印象整理的，**請老師對照手邊課本確認**後再定案。

| 段 | 康軒對應 | 金額範圍 | 第 1 頁可用的錢 | 第 2 頁多出的錢 | 板子 |
|---|---|---|---|---|---|
| ① | 一上「30 以內的數」 | 11～30 | 10、1 | 5 | 十元、一元 |
| ② | 一下「100 以內的數」 | 31～99 | 10、1 | 5、50 | 十元、一元 |
| ③ | 二上「200 以內的數」 | 101～200 | 100、10、1 | 5、50 | 百元、十元、一元 |
| ④ | 二下「1000 以內的數」 | 201～999 | 100、10、1 | 5、50、500 | 百元、十元、一元 |
| ⑤ | 三上「10000 以內的數」 | 1001～9999 | 1000、100、10、1 | 5、50、500 | 千元、百元、十元、一元 |

- 每一段是同一頁的一個參數（暫定 `range=30|100|200|1000|10000`），總覽頁各列一筆。
- 第 1 頁每一格最多 9 個（999 元＝27 個錢），板子每格一列 3 個、最多 3 列。
- 第 2 頁沿用 `docs/題型設計決策.md` §3 的原則：特殊幣放在本位那一格（50 元放十元格、5 元放一元格、500 元放百元格）。
- 第 3 頁的「已經有」與「要湊到」都落在同一段的範圍內。

## 4. 步驟與提示（草案，三種版面共用）

- 第 1、2 頁：①看一看，要拿多少元 → ②拿一拿 → ③數一數，拿對了嗎（按「拿好了」檢查；太多、太少會指出是哪一種錢）。
- 第 3 頁：①看一看，已經有多少元 → ②再拿一些，湊到指定的錢 → ③再拿了多少元（可選）。
- 強提示：虛線錢幣標出還缺幾個、目前要拿的那一格亮綠框、即時顯示「現在有幾元」、拿的時候念出累計金額。
- 弱提示：拿掉虛線錢幣與即時金額，保留分格。
- 無提示：格子標題不放錢幣圖，按「拿好了」才知道對不對。
- 提示強弱一律走 `dashboard/hint-profile.json`（後端 `H('鍵')`），新增的鍵實作時補。

## 5. 使用者定案（2026-11-11）

1. **分兩個版本**：**基本版**＝三頁都用版面 A（錢盒＋位值板）；**應用版**＝三頁都用版面 B（買東西付錢：商品＋價錢牌、收銀盤、錢包）。版面 C 不做。
2. 第 2 頁（特殊幣）：**錢盒限量**——10 元、1 元（有 500 元時 100 元也是）各只有 4 個，5／50／500 元各 1 個；畫面顯示剩幾個。
3. 金額分段：**做第 ①～④ 段**（11～30、31～99、101～200、201～999）；第 ⑤ 段（千元）先不做。
4. 第 3 頁（湊到指定的錢）：分**不跨位**、**跨位**兩個版型；不做「再拿了多少元」那一步；只用普通幣值。
5. 執行方式：計畫定案後派 Sonnet 子代理實作。

6. ~~總覽頁每個版本只留一張卡、進頁面先出任務選單~~（2026-11-11 做過，**2026-11-12 被第 7 項取代**）。

7. **第二輪調整（使用者 2026-11-12）**：
   - **五個一列**：板子上的錢（含虛線錢幣、灰色原有的錢）固定每列 5 個，讓學生習慣五個一數；基本版位值板改成橫帶（百元、十元、一元由上到下各一條，左標題格、右放錢區）；應用版收銀盤每種面額各佔一列。
   - **放完自己記、送出才檢查**：①按「拿好了」不檢查金額；拿掉即時的「現在有 N 元」（提示鍵 `tmNow` 移除）。②數一數改成「自己寫每一種錢有幾個」（可點錢打勾；「念出來」開關：強提示預設開），按「送出」才一起檢查：個數填錯留在②、個數對但金額不對回①（說拿了 N 元、題目要 M 元）、全對完成。取代原本「由大到小點錢標累計」。
   - **步驟①錢上標「數到多少元」**（提示鍵 `tmTally`，強弱有）：先灰色原有的、再新拿的（各由大到小）的累計，每次整盤重算，語音跟著念（共用「念出來」開關）；進②消失，學生自己從頭數。
   - **先拿大的錢**：已經放了小面額就不能再放更大的（先拿大的錢喔），三種提示都限制；湊錢頁灰色原有的錢不算。
   - **金額範圍改成頁面上方的下拉選單**（取代任務選單）；總覽頁各版本 4 張卡（拿出指定的錢／有 5、50 元／湊錢不跨位／湊錢跨位）。
   - 以上取代第 6.3 節中「按拿好了才檢查金額」「②由大到小點著數」「現在有 N 元」「`tmNow`」的敘述；其餘（錢盒限量、放錯格彈回、出題規則）照舊。

## 6. 實作計畫（給執行的人；後端 repo 為主）

### 6.1 端點與參數

`GET /interactive/take-money`（`kind='tm'`，分類 `coin`）：

| 參數 | 值 | 說明 |
|---|---|---|
| `task` | `take`（預設）／`makeup` | 拿出指定的錢／湊到指定的錢 |
| `coins` | `plain`（預設）／`special` | 普通幣值／加入 5、50、500（只在 `task=take`；`makeup` 給 `special` 回 400） |
| `range` | `30`／`100`／`200`（預設）／`1000` | 金額分段：11～30、31～99、101～200、201～999 |
| `ver` | `basic`（預設）／`shop` | 基本版（位值板）／應用版（收銀盤） |
| `cross` | `0`（預設）／`1` | 只在 `task=makeup`：不跨位／跨位 |
| `n`、`mode`、`seed`、`theme_id`、`download` | 同其他互動頁 | `n` 3～10；錯誤參數回 400 |

### 6.2 題目規格（`build_tm_spec()`／`generate_tm()`，放 `backend/interactive_wordprob.py`）

每題欄位（除共用的 `kind`、`hint`、`unit='元'`、`units`、`keyword`、`story`、`ans`）：

- `target`：要拿到的金額（＝`ans`）；`have`：已經有的金額（`take` 為 0）。
- `cols`：板子的格子，`range` 30／100＝`['t','o']`，200／1000＝`['h','t','o']`。
- `box`：錢盒裡每種錢與數量，依面額大到小，例 `[['h',null],['t',null],['o',null]]`（`null`＝不限量）；特殊幣頁例 `[['h',null],['q',1],['t',4],['f',1],['o',4]]`（`range=1000` 再加 `['g',1]`、`h` 也限 4）。只放這一段用得到的面額（30 以內沒有 50 元）。
- `need`：標準拿法（強提示的虛線錢幣），例 `{h:1,t:3,o:5}`；特殊幣頁每位數字 d≥5 用 1 個特殊幣＋(d−5) 個普通幣；`makeup` 是「還要再拿的錢」（差額由大面額往小拆，不超過該面額在目標裡的需要）。
- `haveCoins`：`makeup` 才有，已經在板子上的錢（各位數字個數的普通幣）。
- 應用版另有 `item`／`img`／`counter`（見下）。

出題規則（同一組題不重複；寧可重抽也不出不合理的題）：

- `take`＋`plain`：範圍內任意數，個位不為 0 的題至少佔一半；每格最多 9 個。
- `take`＋`special`：**恰好一個位數 ≥5**（沿用 `題型設計決策.md` §3「特殊幣每題最多 1 種、只 1 枚」），其餘位數 ≤4。30 以內只會用到 5 元。
- `makeup` 不跨位：`have`、`target` 都在範圍內，`target` 每一位數字 ≥ `have` 同一位，差額 ≥ 2，再拿的錢總枚數 ≤ 9。
- `makeup` 跨位：`have` 的個位（或十位）加上差額會超過 9（例：已經有 48，湊到 53；已經有 80，湊到 135）；差額各位數字和 ≤ 9；再拿之後任一格不超過 14 個。
- 應用版商品：從該段對應層級的主題（30／100＝d2、200／1000＝d3，`themes_for_tier`）找 `price_min ≤ target ≤ price_max` 的商品（遵守 `教材設計規範.md` §6「同一商品價格落在同一區間」）；找不到就**不放商品圖**，只放價錢牌與「一共 N 元」。

### 6.3 畫面與步驟（`templates/interactive/coin.js`、`coin.css`；`boot.js` 的 `SEQ`／`LAST`／`menuLinks`；`core.js` 的題型分支）

> ⚠️ 本節的步驟①「按拿好了才檢查」「現在有 N 元」「`tmNow`」與步驟②「由大到小點著數」**已被第 5 節第 7 項（2026-11-12）取代**，以第 7 項為準。

兩個步驟，`LAST=2`，`SEQ={1:tmTake, 2:tmCount}`：

1. **①拿一拿**（標題：基本版「拿出 N 元」、應用版「付 N 元」；湊錢「再拿一些，湊到 N 元」／「再付一些，湊到 N 元」）
   - 左欄板子 `tmBoardHtml(p)`（接在 `visHtml`）：基本版＝上面錢盒、下面 `cols` 格（沿用 `.pvcol` 樣式）；應用版＝商品＋價錢牌、收銀盤（一個放置區，錢放進去自動依面額大到小排）、下面「我的錢包」。
   - **只能拖曳**放進去（比照錢幣位值）；基本版放錯格彈回並說「10 元要放在十元那一格喔」（50 元屬十元格、5 元屬一元格、500 元屬百元格）；強提示拖過即時變綠／紅（`H('liveColor')`）。
   - 放上去的錢**點一下就拿回錢盒**（湊錢頁原來就有的錢是灰色、不能動）。
   - 特殊幣頁：錢盒限量，每疊右上角紅色小標「剩 N」，拿完那一疊變淡不能再拿。
   - 右欄步驟卡：大字目標金額（湊錢頁另有灰色「已經有 N 元」）、提示框（`H('tipbox')`）、「現在有 N 元」（`H('tmNow')`）、「✓ 拿好了」按鈕（板子上有錢才能按）。
   - 按「拿好了」才檢查：金額對＝完成；不對＝`wrongMsg()`「太多了，拿一些回去」／「還不夠，再拿一些」，具體說明指出是哪一種錢（「十元還要再拿 1 個」），連錯達門檻用 `helpCol()` 閃正確的格子。
   - 強提示（`H('tmGhost')`）：格子裡畫虛線錢幣表示還缺的（照 `need`），放一個少一個。
2. **②數一數，拿對了嗎？**：學生由大到小一個一個點錢，每點一個在錢上標出數到多少（100、110、120…），強提示念出累計（「一百、一百一十…」）；先點小的會提醒「先數大的」。湊錢頁從「已經有 N 元」開始往上數，只點新拿的錢。全部點完顯示「一共 N 元」，完成。

提示鍵（**前端 `dashboard/hint-profile.json` 是權威**，改完到後端跑 `python toolkit/sync_hint_profile.py`；兩個都列入 `groups.see`）：

| 鍵 | 強／弱／無 | 說明 |
|---|---|---|
| `tmGhost` | 有／無／無 | 虛線錢幣標出還缺幾個 |
| `tmNow` | 有／無／無 | 即時顯示「現在有 N 元」 |

其餘沿用現有鍵：`tipbox`、`colIcon`、`liveColor`、`flash`、`autoRead`、`readWrongMsg`、`wrongDetailAfter`、`helpAfter`。**不要寫 `level===N`**。
