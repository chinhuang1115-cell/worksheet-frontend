**步驟 0-4 的實作含意**
- **外觀改版（步驟 1）要重畫 EMF**：`backend/coinvalue_media/simple/` 的 `coin_1／5／10／50／100／500.emf`（以及 1000 元對應的 rId7 那張）依 §2 規格重畫——新底色、單層外框、淡灰內圈；photo 不動。內圈線與底色在 EMF 內，Word 與 LibreOffice 都是向量，不用另外處理跑位，但要兩邊各看一次。
- **自由排列不用新機制**：現行已是浮動錨點，自由排列只是把 `posOffset` 改成演算法算出的座標。**要注意** ① `relativeFrom=character／line` 的原點在 Word 與 LibreOffice 因 `docGrid`（`linePitch=405`）不同會差幾 pt（見後端 `docs/guide/free-form-variant.md` 0.4、`word-pdf-consistency.md`）——自由排列座標範圍大，請把一題所有錢幣錨在**同一個段落**、用同一個原點，並兩邊量測；② **傾斜**用 `pic:spPr/a:xfrm rot="…"`（單位 1/60000 度），**需先驗證 LibreOffice 轉 PDF 時旋轉 EMF 不糊、位置不偏**（若有問題，備案是只在旋轉的幣改用 PNG）；③ **交疊的上下層**用 `relativeHeight` 遞增（後放的數字大），`allowOverlap="1"` 已有；④ 傾斜後 `posOffset` 是未旋轉外框的左上角，旋轉繞中心，座標要用中心換算（模擬用 `cx,cy` 為中心）。
- 若上述 Word／LibreOffice 一致性難以達成，備案是用 `toolkit/bake_region.py`／`/bake` 把一題的錢幣區烘成一張圖（位置固定、兩邊一致，但老師不能在 Word 裡編輯錢幣）。

## 2. 共用碰撞與放置模組（B、C 層共用，只寫一次）

- [ ] 碰撞：**圓形幣用圓心距離**（不要用外接方框，否則十位區會誤判放不下）；長方形幣用**旋轉後的外接框**（w′＝w·cosθ＋h·sinθ，h′＝w·sinθ＋h·cosθ）；最小間距約 5 px。
- [ ] 放置演算法：大的先放、隨機取座標、放不下整輪重來；**連續失敗要報錯，不要靜默擺歪或重疊**（交接文件 §3.4）。
- [ ] 參考實作：`mock-coin-free/coin_geom.js`、`coin_mix_free.html`、`coin_special_free.html`（可直接讀程式看座標與參數）。

**過關條件**：單元測試——最密題連跑數十份，不報錯、不重疊、不出框。

## 3. 試水：`coincarry1000` L2（B 半自由 → C 完全自由）

先做版面最大、錢幣種類最多的 `coincarry1000` L2（500 元，四欄，每頁 4 題）。

- [ ] **B 半自由**：區＝位值板欄界各內縮 **8 px**（區寬千 67／百 127／十 38／個 34）；同面額在自己的區內隨機；**特殊幣 500 元固定在百位區左上角（距邊約 4 px），大小不放大**；無欄頭、無虛線、無十進位換行；**長方形幣傾斜 ±4°**。
- [ ] **C 完全自由**：全部面額在框內（各邊縮 6 px）隨機；**位值傾向 B 設定**（本題出現的面額由高到低排目標位置 `tf＝(i+0.5)/種數`，x 取常態分布 sd＝0.16×框寬、10% 純隨機，放不下逐步放寬 sd）；500 元隨機位置、不放大；**長方形幣傾斜 ±10°**。
- [ ] 共通：框下方整理欄保留（欄界沿用現行、每格左上角小幣值標示）、第 1 題固定示範題（劃掉舊值＋橘色進位）、答案正確、頁數與位值板版相同、命名「（半自由排列）」「（完全自由排列）」、下載檔名加「半自由排列」「自由排列」。
- [ ] 產生新 sample PDF，registry 新增排列維度（不要沿用 L 編號）。

**過關條件**（交接文件 §7）：不重疊不出框、特殊幣位置符合層級、題目與答案和位值板版一致、頁數不變、Word／LibreOffice 都正確、灰階清楚。對照圖：`coincarry1000_L2_semi_tilt_new.png`、`coincarry1000_L2_free_ltr.png`。

## 6. 加碼：傾斜與交疊的細節（可與步驟 3–5 同步，也可分開驗收）

- [ ] 傾斜：B ±4°、C ±10°，圓形幣不傾斜（轉圓看不出差別、轉字只會降低可讀性）；500 元在 B 層固定位置但也傾斜。
- [ ] 交疊（**預設開啟**，做成可開關參數，`overlap＝0.3`）：每對交疊面積各自 ≤ 30%、< 4% 不要、**不蓋到對方中央數字保護區**、每枚最多與 1 枚交疊、約 60% 的幣可交疊；B 層特殊幣不交疊（交接文件 §3.7）。
- [ ] 位值傾向的 `sd`（0.16）與純隨機比例（10%）做成可調參數，日後要改 C 版（0.28／25%）才不用改程式。
