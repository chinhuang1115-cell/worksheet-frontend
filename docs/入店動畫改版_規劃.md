# 入店動畫改版：每位客人都走進來、店員出來打招呼（使用者 2026-11-14）

## 需求（使用者原話）

> 有關進店動畫，我希望每一位新的客人都有，而不是現在的第一位客人才有動畫；另外店員看到顧客進店，人應該要出來打招呼，而不是只有聲音。

## 現況（後端 `backend/templates/game_shop.html` 的 `enterShop(first, tk)`，約第 652～687 行）

- 每位客人：門鈴「叮咚」＋店員對話框（`#R.talk`）念 `SHOP.greet`。
- 只有第 1 位客人（`first===true` 且有 `SPEC.faces.walk`）：顧客半身從左邊踏進 3 步 → 店員歡迎 → 顧客縮小飛回左上角頭像 → 「我的錢包」淡入。
- 後端 `game_shop.py` 第 244 行 `faces.walk` 只內嵌**第 1 位客人**的走路圖（字串）。
- `startRound(false)` 有兩個呼叫點：①下一位客人（第 1166 行）②切提示強弱＝這位客人重來（第 1179 行）。

## 定案的做法

### 1. 每位新客人都走進來

- `game_shop.py`：`faces.walk` 改成**字典** `{顧客編號: 圖}`，內嵌本場用到的每位顧客走路圖（最多 4 張、每張約 52KB）。
- 前端取圖：`F.walk` 是字典就取 `F.walk[R.cus]`；是字串（舊離線檔）就維持舊行為（只有第 1 位用）。
- `startRound(first, fresh)` 加參數區分：
  - 第一位（`startRound(true)`）與下一位客人（第 1166 行）→ **完整動畫**。
  - 切提示強弱（第 1179 行）＝同一位客人重來 → **不播走路、店員不出來**，只保留門鈴＋對話框（＝現在非第 1 位客人的短版）。
- 「我的錢包等頭像出現才出現」（`#L.entering`）每位客人都套用。

### 2. 店員出來打招呼（新增）

- 圖：`SPEC.faces.clerk`（店員正面半身，152×200 原圖）。
- **出場**：顧客走完 3 步後，店員從右側頭像位置（`#Rface img`，期間 `visibility:hidden`）**放大並移到中間櫃台區右側**，像從櫃台後面站出來（0.5 秒，ease-out）。
  - 大小：高 `CH = min(220, 遊戲區高 × 0.32)`，寬 `CH × 152/200`（不要放大超過原圖 1.5 倍以免糊）。
  - 位置：外框下緣貼齊中間 `.counter` 的上緣（像站在櫃台後面露出上半身）；右緣在 `#C` 右內緣左邊約 20px。**不可與顧客半身重疊**；1024×768 量不下時再往右／縮小，以三種畫面實測為準。
  - 外框同樣用 `overflow:hidden` 的 `.clerkbox` 包 `<img>`（照顧客 `.walkbox` 的寫法：外框管位移、裡面的圖管動作，兩者不要合在同一個元素）。
- **打招呼**：站定後鞠躬 1 次（圖在框內 `translateY(8px) rotate(0)`＋ `scaleY(.96)` 下去再回來，約 0.6 秒，`transform-origin: bottom`），同時店員頭上方跳出一個臨時對話框 `.enterbub`（文字 `SHOP.greet`，樣式比照 `.bub` 的店員藍色，`bubpop` 動畫）並念出來；等語音念完或 2 秒（取先到者），且最短停 1.2 秒。
  - 這段期間**不要**再讓 `#R` 加 `talk` 顯示第二個對話框（避免兩個「歡迎光臨」）；`startRound` 原本就會 `bubble('clk', SHOP.greet)`，動畫結束後右側對話框照舊。
- **回去**：店員縮小飛回 `#Rface` 頭像位置（0.6 秒），**同時**顧客縮小飛回左上角頭像（原本的 0.7 秒那段）；兩邊結束、`lay.remove()` 後頭像才顯示，不會出現兩個人。然後錢包淡入。
- 沒有 `SPEC.faces`（舊離線檔）→ 不出店員，維持舊的對話框版。

### 3. 時間軸（每位新客人）

| 時間 | 動作 |
|---|---|
| 0 | 門鈴叮咚 |
| 0.5 s | 顧客半身踏進 3 步（1.1 s，現有） |
| 1.6 s | 店員從右側站出來（0.5 s） |
| 2.1 s | 鞠躬＋對話框＋念「歡迎光臨…」（1.2～2 s） |
| ≈3.8 s | 店員、顧客同時縮回頭像（0.7 s）→ 錢包淡入 |

整段約 4.5～5 秒，與現在第 1 位客人差不多。

### 4. 不變的

- `?noanim=1` 完全跳過（測試、縮圖用；`make_thumbs.py` 已帶）。
- `.enterlay` 擋操作；頂端列可按；`TOKEN` 改變就乾淨中止（`finally` 移除整層、還原兩個頭像的 `visibility`、拿掉 `entering`）。
- 早餐店、麵包店共用同一份程式，兩家都要驗。

## 驗收

1. 既有測試照跑都過：`node toolkit/test_game_shop.js`、`node toolkit/test_game_shop_free.js`（都帶 `noanim=1`）。
2. 另寫 Playwright 檢查（不帶 `noanim`），早餐店、麵包店各一次：
   - 第 1、第 2 位客人都出現 `.walkbox`；兩位都出現 `.clerkbox`，且出場時 `#Rface img` 是 hidden、動畫結束後恢復。
   - `.clerkbox` 與 `.walkbox` 的矩形不重疊；`.clerkbox` 完整在視窗內。
   - 動畫中途切提示強弱：`.enterlay` 立刻消失、兩個頭像都恢復、沒有殘留 `.clerkbox`／`.enterbub`；重來的那一輪**沒有** `.walkbox`／`.clerkbox`。
   - 1024×768、1280×800、1366×768：`document.documentElement.scrollHeight === innerHeight`。
   - 動畫期間只有一個「歡迎光臨」對話框可見。
3. 截圖（deviceScaleFactor 2）：顧客走到定點、店員鞠躬中、縮回後三張，給使用者看。
4. 縮圖不用重產（`noanim=1` 拍的畫面不變）。
