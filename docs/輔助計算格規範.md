# 輔助計算格規範（草稿）

> 狀態：草稿。「現況」欄依 `assets/mul2x1_basic_grid_sample.pdf` 實際版面整理；標示 **【待確認】** 的項目是建議值或生成程式碼無法從本 repo 驗證，請老師確認後定案。
> 本 repo 為前端，計算格實際繪製在 PDF／Word 生成程式；定案後請同步回生成程式。

## 1. 目的

以直式計算格把「位值對齊」具象化，降低認知負荷，讓學生把注意力放在運算步驟而非排版。

## 2. 三種鷹架層級（漸進撤除）

| 層級 | 名稱 | 提供的支持 |
|---|---|---|
| 1 | 示範引導 | 先看完整示範（連加→乘法對照），再自己算 |
| 2 | 計算格 | 附位值格線與進位輔助格，學生填寫 |
| 3 | 無輔助格 | 只有純直式，無格線 |

同一題型（如 N209D）應同時提供三種，老師依學生程度挑選；由 1 → 3 逐步撤除。

## 3. 計算格版面（現況）

- **格線**：淺灰細線，每一位數一欄；不搶運算符號與橫線的視覺。
- **位值對齊**：格子由右往左為個、十、百位，數字靠右對齊。
- **運算符號**：`×`、`+` 放在最左側獨立格。
- **結果橫線**：粗黑實線，位於被乘數／乘數與答案之間，清楚分隔「算式」與「答案」。
- **答案列**：橫線下方預留一列空格，欄數＝可能的最大位數。
- **排列**：每頁 9 題（3×3），每題外框獨立、題號用圈號（❶❷❸…），題目寫在格子上方，如 `50×8 = (   )`。
- 版頭：單元名稱、姓名欄；頁尾：教室標示與頁碼。

## 4. 規範項目（建議）

1. **欄數規則**【待確認】：欄數 = 乘積最大位數 + 1 個運算符號欄。
2. **進位輔助格**【待確認】：「計算格」層級在各位數上方提供小進位格；「無輔助格」不提供。
3. **色彩**：格線用淺灰、重點（示範中被強調的算式、箭頭）用淡色底，不用高彩度色，避免干擾。
4. **黑白列印**：所有輔助資訊在黑白列印下仍可辨識（不得只靠顏色區分）。
5. **格子尺寸**【待確認】：格寬須夠學生手寫一位數字，建議不小於 8 mm；目前值待從生成程式讀出。
6. **一致性**：加、減、乘、除各題型共用同一套格線樣式與符號位置，換題型學生不必重新適應。
