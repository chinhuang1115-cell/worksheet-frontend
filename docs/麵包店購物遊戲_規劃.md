# 麵包店購物遊戲（互動版）規劃

> 2026-11-10 使用者提出並定案；**與早餐店購物遊戲是同一份程式換主題**（流程、版面、提示強弱、直式「算一算」、換人畫面都一樣，早餐店以後改什麼，麵包店也跟著改）。共用的定案事項、流程與歷次回饋見 [`早餐店購物遊戲_規劃.md`](早餐店購物遊戲_規劃.md)；實作筆記在後端 repo `docs/guide/game-shop.md`「多家店」。菜單草案圖：[`mock-bakery-shop/A_菜單草案.png`](mock-bakery-shop/A_菜單草案.png)。

## 已定案（使用者 2026-11-10）

| 項目 | 決定 |
|---|---|
| 玩法 | **沿用早餐店玩法**（顧客／店員輪流：點餐 → 算錢 → 付錢 → 收錢找錢 → 點收 → 收據），**再加第 5 關「哪袋划算」**（紅袋藍袋比單價；2026-11-10 由「一盒／一袋」改版） |
| 網址 | 後端 `/game/bakery-shop?stage=1~5`（早餐店是 `/game/breakfast-shop`，第 1～4 關） |
| 入口 | 互動遊戲導覽頁 `games/`（商店街）讀 `dashboard/catalog.json` 的 `game-bakery-1`，自動多一間「麵包店」 |
| 商品圖 | 與早餐店同一套：Microsoft Fluent Emoji 3D（MIT），授權 `images/麵包店/LICENSE.txt`（前後端各一份）；圖庫主題 `麵包店` 標 `reserved`（只給遊戲用） |
| 菜單（12 樣，每場擺 8 樣） | 吐司 35（條）、可頌 30（個）、法國麵包 40（條）、貝果 25（個）、杯子蛋糕 40（個）、草莓蛋糕 45（塊）、甜甜圈 20（個）、餅乾 10（片）、布丁 25（個）、鬆餅 30（片）、牛奶 15（杯）、果汁 20（盒；圖是鋁箔包） |
| 裝潢（使用者 2026-11-10：**每個店家的裝潢都要不同**） | 麵包店：粉紅奶油色波浪邊雨棚、巧克力色招牌「🥐 香香麵包店」、粉色展示櫃（菜單牆）、草莓奶油色櫃台、淡粉底色。**顧客橘、店員藍是角色色，各店一樣不換**。以後新增店家也要有自己的一組裝潢 |
| 對話 | 店員「歡迎光臨！要買什麼？」、顧客「我想要買麵包。」「我拿好了。」；點餐卡「把東西拖到托盤」（菜單有飲料，不寫「麵包」） |

## 第 5 關：哪袋划算（兩個牌子比單價；2026-11-10 改版）

> 舊版「一盒／一袋：菜單寫整盒價錢、算 1 個多少」**已取代**。使用者 2026-11-10：東西平常是單賣，整袋、整包是促銷；生活中要算的是「哪一種買法比較划算」。使用者選**只做兩個牌子比單價**、**模擬圖 B3 價錢天平**（`mock-bakery-shop/B3_比單價.png`；B1 價卡、B2 比價單、B4 拆開排一排未採用）、名稱**紅袋／藍袋**、**大多某一袋便宜，偶爾一樣**、**比完先算便宜多少，再付錢找錢**。

| 步驟 | 畫面 | 練到的能力 |
|---|---|---|
| ① 比一比 | 菜單牆換成比價區：紅袋、藍袋（個數不同，袋子下方「1 個 □ 元」價卡）＋天平。學生依序算兩袋「1 個多少元」（直式除法，或直接填） | 除法（二位數 ÷ 一位數） |
| ② 選划算的 | 兩個單價放上天平，**便宜（輕）的那邊翹起來**，一樣就平；按「紅袋／藍袋／一樣」 | 比大小 |
| ③ 便宜多少 | 「25 － 20 ＝ □ 元」（直式減法，或直接填）；一樣價錢就跳過 | 減法 |
| ④ 買划算的 | 把那一袋拖到托盤（一樣價錢時哪一袋都可以）→ 付錢 → 店員找錢 → 點收 | 錢幣 |
| 收據 | 「藍袋鬆餅（3 片）60 元」「1 片：60 ÷ 3 ＝ 20 元」「紅袋 1 片 25 元，藍袋便宜 5 元」 | 整理紀錄 |

出題規則：
- 品項：可頌、貝果、甜甜圈、布丁、鬆餅、杯子蛋糕、吐司（飲料不做；**餅乾單賣 10 元，袋裝再便宜就低於 10 元，不放**）。
- 兩袋個數不同（2～5 個）；**袋裝 1 個的價錢不高於單賣價、最多便宜 10 元**（促銷才合理）；兩袋 1 個差 5 或 10 元。
- 七成的題目是「**整袋比較貴、但 1 個比較便宜**」（不能只看整袋價錢）；約一半的場次有 1 位客人兩袋 1 個一樣價錢。
- 整袋 10～99 元、可以整除；錢包照比較貴的那袋準備。
- 提示：強提示自動念、正在算的那袋發光、選錯後天平輕的那邊發光、要拖的袋子發光；無提示前幾次錯只說「再試一次」。
