# 購物遊戲：角色聲音依人像的性別、年齡（使用者 2026-11-14 定案，**已實作**）

## 問題

使用者：「店員、語音都有男女之分，但卻沒有對應上」。

- 現況（後端 `game_shop.html` `pickVoice()`）：聲音照**角色**固定分配，顧客＝像女聲的、店員＝像男聲的。
- 人像（`SPEC.faces`）每場隨機抽：
  - 店員 `clerk_1` 女（馬尾）、`clerk_2` 男（眼鏡）、`clerk_3` 女（捲髮）、`clerk_4` 男（白髮爺爺）；
  - 顧客 `customer_1` 男孩、`2` 女孩、`3` 奶奶、`4` 爸爸。
- 所以抽到女店員、男孩、爸爸時，聲音就對不上。

## 定案做法

1. **人像標性別、年齡**：後端 `game_shop.py` 加一張表 `FACE_INFO`：
   - `clerk`：`{1:('f','adult'), 2:('m','adult'), 3:('f','adult'), 4:('m','old')}`
   - `customer`：`{1:('m','child'), 2:('f','child'), 3:('f','old'), 4:('m','adult')}`

   `SPEC.faces` 多帶兩樣東西：
   - `clerkNo`（這場店員的編號）；
   - `info`：`{clk:{g,age}, cus:{編號:{g,age}}}`，只放這場用到的人。
2. **聲音跟著人走**：`speak(..., 'cus')` 用本回合顧客 `R.cus` 的性別，`'clk'` 用這場店員的性別。旁白 `nar` 不變。
   - `pickVoice()` 改成挑出 `VAUTO = {nar, f, m}`：女聲＝像女聲的第一個；男聲＝像男聲、而且和女聲不同的第一個。
   - **沒有男聲時 `m = null`**，男生角色就用女聲加低音調模擬。
3. **音調依年齡與性別**（`vPitch(who)` 改看人）：

   | 年齡 | 音調 | 語速 |
   |---|---|---|
   | 小孩 child | 1.3 | 照原本 |
   | 大人 adult | 1.0 | 照原本 |
   | 老人 old | 0.85 | ×0.9 |

   - **男生角色卻用女聲**（裝置沒有男聲）時，音調再乘 0.75，下限 0.5。
   - **顧客和店員最後用到同一個聲音、而且音調差不到 0.15 時**，顧客 +0.12、店員 −0.12，讓學生聽得出是兩個人。
   - 旁白 1.05 不變。
4. **🎙 聲音面板**：
   - 下拉選單由「旁白／顧客／店員」改成「旁白／女生聲音／男生聲音」，試聽照舊。
   - 男生聲音的「自動」選項：沒有男聲時顯示「自動（沒有男聲，用女聲壓低）」。
   - 加一行提示：iPad 可到「設定 → 輔助使用 → 朗讀內容 → 聲音 → 中文（台灣）」下載男聲。
   - `localStorage.ys_game_voice` 改存 `{nar,f,m,spd}`。舊資料 `{cus,clk}` 讀到時做一次轉換：`cus→f`、`clk→m`，只在新鍵是空的時候才轉。
   - `?debug=1` 左下角顯示三個說話者目前的人像編號、性別、年齡、聲音、音調。
5. 沒有 `SPEC.faces` 的舊離線檔：退回舊行為，顧客當女生大人、店員當男生大人。
6. 「算一算」iframe 裡的互動頁語音**不動**。早餐店、麵包店共用同一份程式，一起改。

## 驗收

- 照 `docs/guide/game-shop.md`「語音與音效」的測試做法，用 Playwright `addInitScript` mock `speechSynthesis`，分兩種裝置情境：
  - **甲**：`getVoices` 回 3 個中文聲音（含一個名稱像男聲的，例如 `Microsoft Zhiwei`）；
  - **乙**：只回 1 個女聲（`Mei-Jia`）。
- 用不同 seed 跑到「女店員＋男孩顧客」「男店員＋奶奶」「女店員＋女孩」等組合。檢查每一句：
  - 甲：男生角色用男聲、女生角色用女聲；
  - 乙：男生角色音調明顯比較低（≤ 女生同年齡 ×0.75）；
  - 小孩音調高於大人、老人低於大人；
  - 同一個聲音時，顧客和店員音調差 ≥ 0.15。
- 舊 `localStorage` 資料轉換正確；面板在 1024 寬不擠出畫面（`#bSnd` 右緣不變）。
- `test_game_shop.js`、`test_game_shop_free.js`、`test_game_shop_enter.js` 全過。
- 文件：
  - 後端 `game-shop.md`「語音與音效」補「依人像性別年齡（2026-11-14）」；
  - 後端 `CLAUDE.md` 第 44 條補一句；
  - 前端 `docs/早餐店購物遊戲_規劃.md` 補一句；
  - 本文件標「已實作」並寫上實測結果。

## 實作結果（2026-11-14）

- 後端 `game_shop.py`：`FACE_INFO`；`SPEC.faces` 多 `clerkNo`、`info`。`game_shop.html`：`pickVoice()`→`VAUTO={nar,f,m}`、`person(who)`、`vBase(g,age)`、`vInfo(who)`（`vFor`／`vPitch` 改包它）、`speak` 套 `vInfo` 的聲音／音調／老人慢 0.9；面板與 localStorage 轉換、`?debug=1`。
- 測試 `toolkit/test_game_shop_voice.js`（早餐店、麵包店 × seed 1／2／6 × 裝置甲乙）全過；三支既有遊戲測試全過。
