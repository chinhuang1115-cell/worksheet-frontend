# 生圖流程（Gemini × Cowork × Claude Code）

使用者 2026-11-11 定案：**之後需要圖一律這樣做**。

## 為什麼這樣分工

- 雲端的 Claude Code session 連不到使用者電腦上的 Cowork，也讀不到電腦裡的檔案；
- Cowork 在使用者電腦上，可以操作 Gemini 網頁，但不在 repo 裡；
- 兩邊都接得到使用者的 **Google 雲端硬碟**，所以用雲端硬碟交換檔案。

## 流程

1. **Claude Code 寫指令**：給一整段可直接貼上的 Cowork 指令（格式見下）。
2. **使用者轉貼到 Cowork**：Cowork 在 Gemini 生圖、挑圖、下載、改檔名，上傳到雲端硬碟「**遊戲素材／待處理**」。
3. **使用者回 Claude Code 說「已上傳」**（Cowork 不會自動通知）。
4. **Claude Code 下載處理**：用 Google Drive 連接器依檔名搜尋 → 下載（檔案大時結果會存成 JSON 檔，取 `content` 欄位 base64 解碼）→ 檢查 → `python tools/cutout.py` 去白底 → 對齊／裁切 → 給使用者看預覽。
5. **使用者確認後才放進 repo**。

## Cowork 指令格式（每次照這個結構寫）

1. 任務一句話。
2. **步驟一 生圖**：每張圖的英文提示詞放在程式碼區塊，註明「照原文貼上不要改寫」；附「檢查重點」；**最多重生 2 次**（省 Gemini 額度）。
3. **步驟二 下載改檔名**：明確列出中文檔名（`主體_狀態.png`）。
4. **步驟三 上傳**：「我的雲端硬碟／遊戲素材／待處理」，沒有就建、有就沿用；上傳後打開資料夾確認。
5. **步驟四 回報**：顯示圖、檔名、重生次數、哪點不符合。
6. 「不要刪除或修改資料夾裡的其他檔案」。

## 提示詞寫法（教材用圖）

- 英文寫（Gemini 照英文較穩、較不會冒出亂碼文字）。
- `simple flat vector illustration`、`thick clean dark outline`、`flat colors with minimal shading`、`friendly children's educational game style`：畫面簡單、主體清楚。
- **`Plain pure white background … no shadow … no text, no watermark`**：Gemini 給不了透明背景，白底最好去背；圖上不要有字。
- **會被程式疊東西的部位留空**（例：手不拿錢，錢幣由程式畫，金額與配色才對得上）。
- 角色色照遊戲定案：顧客橘、店員藍（`#5B9BD5`）。
- 同一組動作的多張圖，提示詞除了動作那句以外**完全相同**（角度、構圖、顏色一致，換圖才不會跳）。

## 去背與對齊（`tools/cutout.py`）

- 從四角 flood fill 把相連白底變透明；**被圖形包住的大塊白色（≥3000px，例如手指圍成的洞）也變透明**，小亮點（指甲反光）保留。
- 坑：第一版只從四角填，抓錢手勢指縫中間的洞留白；第二版逐像素找洞跑超過 2 分鐘 → 改成 16px 格點找種子＋`histogram()` 計數，約 3 秒一張。
- 同一組動作的多張圖：Gemini 每張大小、位置都不同。**以固定的部位對齊**（手 → 袖口：縮放到袖口同寬、袖口下緣同 y、袖口中心同 x），再用共同外框裁切。手臂要伸到畫面頂端的，袖口 y 取「各張袖口以上長度」的最小值，免得有一張上端露空。

## 手掌大小不一的修法

同一組動作 Gemini 會畫成不同比例（2026-11-11「張開」手掌比「抓錢」大約一成）。**不要整張縮**（袖口會跟著變窄，對齊就跑掉）；只把袖口以下的手縮小、以袖口下緣中心為錨點貼回，再把袖子疊在最上層蓋住接縫。
